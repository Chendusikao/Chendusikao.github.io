# A 股静态演示：K 线查看交互设计

## 目标

让作品集中的静态 K 线图可用于面试演示：访问者能查看任意一根示例 K 线的价格与成交量，而不暗示存在实时行情或交易能力。

## 交互行为

- 鼠标移入价格图区域时，显示水平和垂直十字线，并显示与鼠标位置最近的一根 K 线。
- 图表右上角的信息浮层显示：日期、开盘、最高、最低、收盘、涨跌幅和成交量；数值来自现有固定示例数据。
- 单击价格图区域后，当前 K 线进入固定选中状态；鼠标移动不会改变浮层内容。
- 再次单击图表空白处，或按 `Esc`，取消固定选中并恢复悬停查看。
- 鼠标离开图表且未固定选中时，隐藏十字线和信息浮层。
- 鼠标样式使用十字光标；移动端点击会选中最近的 K 线。

## 实现边界

- 继续使用浏览器 Canvas 绘图与 `demo-data.js` 的固定数据；不添加网络请求、后端、第三方图表库或实时行情声明。
- 图表绘制函数暴露本次渲染的价格区范围与每根 K 线的 x 坐标，用于将鼠标/触摸位置映射到最近数据点。
- 在页面中新增可访问的、默认隐藏的信息浮层；选中状态通过文本提示和 Canvas 高亮表现，不只依赖颜色。
- 周期或指标切换时清除固定选中状态，避免将旧索引错误映射到新数据集。

## 验证

- 在 PowerShell 冒烟测试中检查演示脚本包含指针事件、`Escape` 取消选中与必要的信息字段，且仍不包含 `fetch()`。
- 执行 Hugo 构建和既有冒烟测试。
- 在浏览器中验证：悬停会显示对应数据，点击会固定，Esc 会取消，切换周期会更新选中状态；桌面和窄屏均无控制台错误。
